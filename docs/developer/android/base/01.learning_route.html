01. Android 入门基础学习路线

JiangMing 2021/5/1 Android 开发基础

本系列的教程属于Android的基础入门应用开发教程，主要介绍 Android 应用入门基础开发相关教程。一个人的精力是有限的，而且也有自己的工作忙，所以不可能去方方面面的详细的介绍每一个相关的知识点（软件的技术迭代也很快），这里主要还是介绍一些基础的概念和相关的示例，所以如需更深的知识体系，还是得自己学会主动去获取知识的能力。

因为 Android 的体系庞大，内容丰富多样，所以这里将系统的描述总结了相关入门原生开发基础的学习方向和路线，涵盖 UI、交互、异步、数据、组件、媒体、扩展、语言与架构、构建发布 等基础功能领域，并衔接当前主流的技术栈（Kotlin + Jetpack）。知识是灵活的，以下内容可能会随着学习深入、Android 的体系架构变化等因素随时调整，此处学习路线仅供参考。

# 学习路线总览

基础篇：01-04（环境 → 结构 → 概念）
UI  篇：05-07（界面 → 布局 → 控件 → 自定义View → 对话框菜单 → 资源适配）
交互篇：08-09（触摸事件+物理按键 → 数据存储）
异步篇：10（Handler消息机制 → 线程与线程池 → ANR与主线程）
数据篇：11-12（网络编程 → 数据解析与图片加载）
组件篇：13-17（四大组件 → Intent → 权限机制 → 通知 → WebView）
媒体篇：18-20（绘图动画 → 音视频 → Camera）
扩展篇：21-22（位置地图 → 传感器）
进阶篇：23-26（Kotlin → Jetpack → 构建发布 → 进阶展望）

# 详细章节规划

# 基础篇

  • ✅ 01 学习路线（本文）
  • ✅ 02 开发环境搭建：Android Studio、SDK、模拟器、调试
  • ✅ 03 项目结构与资源：工程目录、资源分类与使用
  • ✅ 04 应用基础知识：系统架构、应用组件、清单文件

# UI 篇

  • ✅ 05 用户界面：UI 体系概述
  • ✅ 06 布局组件：LinearLayout / RelativeLayout / ConstraintLayout 等七大布局
  • ✅ 07 常用控件：文本、按钮、图片、列表（ListView/RecyclerView）、AdapterView 等控件（07.01-07.19）
  • ✅ 07.20 自定义View与绘图：绘制三大流程（onMeasure/onLayout/onDraw）、MeasureSpec、Paint/Canvas/Path/Shader、三种自定义方式实战
  • ✅ 07.21 对话框与菜单：AlertDialog（列表/单选/多选/自定义）、DialogFragment、BottomSheetDialog、PopupWindow、WindowManager 系统级悬浮窗（SYSTEM_ALERT_WINDOW 权限）、Toast/Snackbar、Menu 体系（Options/Context/Popup 菜单）
  • ✅ 07.22 资源适配与多主题：屏幕密度适配（dp/sp/drawable 分级）、多语言国际化、深色模式（DayNight）、横竖屏与多窗口适配

# 交互篇

  • ✅ 08 事件处理：
    • ✅ 08.01 触摸事件处理：MotionEvent 与事件序列、监听/回调两种处理方式、事件分发机制（U型传递与源码级规则）、ACTION_CANCEL、多点触控、GestureDetector、坐标系、滑动冲突（外部/内部拦截法）
    • ✅ 08.02 物理按键事件处理（HardKey）：KeyEvent 与按键体系、onKeyDown/onKeyUp、返回键与 OnBackPressedDispatcher、音量键/电源键处理、Home 键监听的边界、软键盘（IME）事件、按键与焦点系统（焦点移动/遥控器适配）、实体键盘与外设（游戏手柄）
  • ✅ 09 数据存储：SharedPreferences（apply/commit、DataStore 衔接）、文件存储（内部/外部、分区存储、FileProvider）、SQLite 与版本迁移、Room/ORM 对比

# 异步篇

  • ✅ 10 线程与消息机制：
    • ✅ 10.00 索引与线程体系概述：主线程/工作线程职责边界、UI 单线程模型、异步方案全景
    • ✅ 10.01 Handler 消息机制原理：四大角色、消息循环全景图、主线程 Looper 与 epoll 休眠、Message 对象池、HandlerThread、派发优先级、postDelayed 与同步屏障、内存泄漏防治
    • ✅ 10.02 线程与线程池：裸 Thread 问题、ThreadPoolExecutor 七参数与四步决策图、拒绝策略、Executors 禁用原因、手写线程池、并发基础工具、废弃方案回顾
    • ✅ 10.03 ANR 与主线程规则：触发条件表、traces 定位法与堆栈速查、主线程红线清单、耗时任务标准范式、启动期防范与 StrictMode

# 数据篇

  • ✅ 11 网络编程：
    • ✅ 11.00 索引与网络基础：HTTPS 请求生命周期图、HTTP 报文与方法语义（幂等）、状态码处理原则、TLS 握手要点、Restful、Android 网络约束
    • ✅ 11.01 OkHttp：同步/异步、四种请求体、拦截器责任链架构图、应用/网络拦截器、连接池、HTTP 缓存、单例与高频陷阱
    • ✅ 11.02 Retrofit：分层架构图（声明→动态代理→OkHttp→转换器）、六类注解、单例构建、回调线程切换、baseUrl/注解配套陷阱
    • ✅ 11.03 网络进阶与封装：WebSocket 握手示意图、心跳/重连/消息可靠性、弱网三层缓存策略、证书锁定与安全红线、网络层统一封装（错误归一化）
    • ✅ 11.04 常用网络知识补全：HTTP 协议演进图（1.1/2/3 队头阻塞主线）、HTTPDNS 防劫持、NetworkCallback 网络监测、抓包调试工具链、Range 断点续传下载、MQTT 概念、流量统计
  • ✅ 12 数据解析与图片加载：
    • ✅ 12.00 索引与概述：解析链路全景图（序列化/反序列化）、JSON 与 XML 生态分工、解析须在子线程
    • ✅ 12.01 JSON 解析：Gson 双向工作流图、fromJson/toJson、TypeToken 泛型擦除、@SerializedName/@Expose、Date/null 配置、六条坑清单、org.json/Moshi/kotlinx.serialization 选型
    • ✅ 12.02 XML 解析：DOM/SAX/Pull 对比、XmlPullParser 完整实战
    • ✅ 12.03 数据模型（DTO）设计：DTO/VO/Mapper 分层架构图、七条设计原则、端到端优秀实践案例（含单测）、反例对照表
    • ✅ 12.04 图片加载：Bitmap 内存账、Glide 基本用法与生命周期感知、三级缓存管线图、列表复用错图排查、Glide vs Coil 选型

# 组件篇

  • ✅ 13 四大组件：
    • ✅ 13.00 组件总览：四大组件定位对比图、组件托管四条宪法、manifest 注册与 exported、组件与进程/线程关系
    • ✅ 13.01 Activity：生命周期全景图与八条典型路径、状态保存/恢复（Bundle 边界与 ViewModel 预告）、四种启动模式栈示意图与 FLAG、ActivityResultLauncher、多屏启动指定 DisplayId、七条陷阱清单
  • ⏳ 14 Intent 与组件通信：显式/隐式 Intent、IntentFilter 匹配规则、Bundle、PendingIntent、进程与 IPC 概念
  • ⏳ 15 权限机制：权限分类（普通/危险/特殊）、运行时权限申请流程、权限组、特殊权限（悬浮窗/通知/安装包/精准定位）、权限最佳实践
  • ⏳ 16 通知 Notification：NotificationChannel 与通知体系演进、基本通知构建（横幅/锁屏/角标展示级别）、PendingIntent 与通知交互、通知样式（BigText/Inbox/Progress/MediaStyle）、前台服务与常驻通知、通知权限与 Android 13+ 行为、特殊场景（全屏 Intent、分组通知）
  • ⏳ 17 WebView：WebView 基本使用与配置（WebSettings/WebViewClient/WebChromeClient）、加载本地与远程页面、Java 与 JavaScript 互调（JavascriptInterface）、缓存策略、常见坑与安全（XSS/文件访问/混合内容）

# 媒体篇

  • ⏳ 18 绘图和动画（索引 + 分节）：
    • 18.00 索引与动画体系概述
    • 18.01 View 动画（补间动画与帧动画）
    • 18.02 属性动画（ValueAnimator/ObjectAnimator）
    • 18.03 动画与自定义 View 的结合
  • ⏳ 19 音视频（索引 + 分节）：
    • 19.00 索引与 Android 多媒体框架概述（MediaPlayer 框架架构、Stagefright/NuPlayer 演进、MediaCodec 编解码管线、ExoPlayer 定位）
    • 19.01 音频播放（MediaPlayer/ExoPlayer、AudioFocus 焦点管理）
    • 19.02 MediaSession 媒体会话（MediaSession/MediaController、后台播放与系统媒体控制卡片、锁屏/耳机/蓝牙按键联动、MediaBrowserService 浏览）
    • 19.03 音频录制（AudioRecord/MediaRecorder）
    • 19.04 视频播放与录制（SurfaceView/TextureView 渲染、MediaCodec 基础）
  • ⏳ 20 Camera 相机（索引 + 分节）：
    • 20.00 索引与相机体系概述（CameraX 与 Camera2）
    • 20.01 预览（Preview/权限/兼容性）
    • 20.02 拍照与图片分析
    • 20.03 录像

# 扩展篇

  • ⏳ 21 位置与地图：定位权限、FusedLocationProvider、地理编码、地图 SDK 接入
  • ⏳ 22 传感器：加速度计/陀螺仪/磁场/光照、步数计步、SensorManager 使用规范

# 进阶篇

  • ⏳ 23 Kotlin 基础入门：语法速览、空安全、扩展函数、数据类与密封类、协程与 Flow 入门、与 Java 互操作
  • ⏳ 24 Jetpack 架构组件（索引 + 分节）：Lifecycle / ViewModel / LiveData / Room / Navigation / DataStore / WorkManager，MVVM 实战
  • ⏳ 25 构建与发布：Gradle 基础（依赖管理与构建变体）、应用签名、打包发布（APK/AAB）、多渠道打包、代码混淆（ProGuard/R8）
  • ⏳ 26 进阶展望：单元测试与 UI 测试入门、性能优化方向（Profiler/LeakCanary/启动优化等）、模块化、NDK 入门、蓝牙/WiFi/近场通信、Compose 声明式 UI 概览（学习方向的指引，不展开）
